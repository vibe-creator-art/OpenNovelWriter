description: "对已有正文或摘要的小说，从缺失处按章补全 Story State。每完成一卷后询问是否继续。"

## Purpose
把已经写好的章节补进 Story State。不改摘要、不改正文、不新建词条。按章推进，每完成一卷就停下来问用户是否继续。

## When to use
- 小说已经写了一部分，账本是空的，需要从头入图。
- 前面若干卷/章已经有 Story State，后面大面积缺失，要从缺口接着补。
- 用户说回填剧情状态、按卷同步故事状态、旧稿补账本时使用。

不要用本技能做：刚写完一场的日常入图（用「预设-总结场景+更新经历/关系+同步故事状态」）；只修摘要改过但还没同步的来源（用「预设-修复过期来源」）；导入后还没有摘要/词条（用「预设-全书初始化」）。

## Instructions
先读内置 `story-state` 技能。从 `novel/outline.md` 取 `novel_id` 和卷/章/场顺序。

### 1. 定位从哪开始
读 `novel/outline.md` 和 `novel/story-state/`（`moments.md`、`entities.md`、`facts-active.md`、`outdated.md`）。

- 用户指定了从某卷或某章开始：听用户的。
- 账本为空：从第一卷里、第一场有摘要的章开始。
- 账本已有一部分：按 outline 顺序找到第一处「有摘要、但还没入图」的章，从那里开始。不要无故把已经同步且 hash 未变的场再抽一遍。
- 开始前用几句话告诉用户：从哪一卷哪一章起、本卷大概有多少场有摘要、哪些场没有摘要会跳过。用户若要改起点，先改再动手。

不要只传 `novelId` 拉全图。需要总览时，只在定位缺口这一次看 `novel/story-state/`，之后按章用带 `query` / `entityId` 的 `query_story_state`。

### 2. 按章同步
在当前卷内，按 outline 一章一章做完再进下一章。一章里有多场就按场顺序。一次不要开多个 subagent 并行写账本。

对每一场：
- **没有摘要**：跳过，记下来。不要擅自写摘要，也不要读完全文再发明摘要。若本卷大量场都没有摘要，停下来告诉用户：无法入图，需要先总结场景或跑全书初始化。
- **有摘要**：从**已保存的场景摘要**入图，不要为入图去改摘要或正文。不要把抽到的实体升级成词条，不要 `edit_term`。
- **已在 `outdated.md` 且落在当前进度内**：按新摘要同步。小改只续挂旧 `factId`；大改按新摘要重抽，不要 copy-forward。范围以外的过期来源不要顺手全库修。
- **hash 未变、工具 skip**：视为已完成，进入下一场。

入图规则（每场都遵守）：
1. 用带 `query` / `entityId` 的 `query_story_state` 按本场出现的名字查已有实体和相关 Fact，复用，不要因措辞变化新建。
2. 本场需要入账但还没有实体的，用 `upsert_story_entity`。称谓、简称用 `add_story_entity_alias`（抽取用 `EXTRACTED`）。
3. 只在摘要里有明确时间锚点、状态转折、或必须表达先后时才创建 Moment。一场可以是 0、1 或多个。只传自然语言 `label` 和可选 `afterMomentId`，不要提交整数顺序。 `label`是故事的时间表，比如奥瑞利亚纪年1902年，请尽量和已有的保持一致，若没有已有的moment label，请询问作者纪年怎么处理。
4. 调用 `sync_scene_story_episode`。`predicateKey` 用稳定大写键（如 `LOCATED_AT`、`OWNS`、`STATUS`、`KNOWS`）。新 Fact 必须能从摘要直接读出；实体宾语优先 `objectEntityId`。已存在的命题只传 `factId`。故事世界里状态真的变了，才用 `closeFacts`。
5. 不要对场景来源使用 `retract_story_episode` 或 `assert_story_facts`。

### 3. 一卷结束必须停下
当前卷里该同步的章都处理完后，立刻停止，不要自动进入下一卷。

汇报：本卷同步了哪些章、跳过了哪些无摘要的场、是否还有本卷范围内的过期来源没修完。然后明确问用户：是否继续下一卷。

- 用户同意：按同样方式做下一卷。
- 用户要先检查、停在这里、或改范围：等下一次指示。
- 后面没有更多有摘要的章了：说明回填结束，列出全书仍缺摘要、因此没入图的场。

## Output
每章用一两句话即可。每卷结束必须给出本卷小结，并询问是否继续。不要默认列出全部 Fact。
